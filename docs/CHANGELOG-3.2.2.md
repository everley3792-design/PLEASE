# 3.2.2 修整紀錄

## 卡頓與閃爍

- 將環境更新、島民與對話的持續工作集中到同一個更新迴圈，避免選定角色重複更新。
- 合併靜態花海與草地的獨立繪製元素；解碼完成才交換圖片，避免載入中的空白幀。完整動態模式仍可使用原裝飾。
- 停止隱藏頁面、被面板遮住的場景與 App 背景中的無效動畫／天氣工作。
- 移除舊家具排序與新島民排序互相覆寫的逐幀行為，保持角色、陰影與家具的深度一致。
- 修正切頁／旋轉後仍以舊版 DOM 座標量測角色地面高度的問題。
- 鏡頭追蹤改用地面座標並加入緩衝區，角色跳躍不再讓整座小島上下晃動；不再定時拆卸重建相機圖層。
- 以 Canvas Path2D 判定同一條 SVG 地形路徑，避免尋路時強制計算 DOM 版面。
- 雲朵改由合成動畫移動；降低雨雪效果的繪製解析度／密度，保留天氣識別度。
- 修正夜間星空與螢火蟲的狀態判斷讀到舊值、未隨時間顯示的問題；天空背景直接接收完整色票，避免夜間沿用白天色彩。
- 對話使用角色與鏡頭的數值座標；移除來源泡泡的強制版面量測與不可見的逐字動畫。
- 個性資料只在載入新紀錄時正規化，減少持續配置臨時物件。

## 介面與操作

- 統一 HUD、面板、色彩、圓角、文字層級與陰影；移除動態場景上的即時模糊。
- 導覽預設顯示文字，仍保留自訂排序、顯示項目與隱藏文字的功能。
- 固定 HUD 的大小與透明度，減少閒置／觸碰時反覆伸縮與淡入淡出。
- 保留單一面板轉場，移除面板內每一列再輪流出現的多重動畫。
- 對話一次顯示最多兩則（寬螢幕最多三則），處理名稱標籤、邊界與泡泡重疊。
- 返回鍵優先關閉拍照、快捷資訊、日常抽屜與背包，再回首頁。
- 新增流暢、省電與完整動態設定，並保存選擇；尊重減少動態的偏好。
- Android 拍照可隱藏 HUD 後，使用 PixelCopy 擷取 App 畫面，再透過系統另存 PNG。

- 完整備份還原接回 2.9–3.2 的個性、需求、技能、目標、圖鑑、日誌、擺設與畫面／導覽偏好，轉換其中的角色引用 ID，保留既有自創角色。
- 延伸資料先驗證，成功還原後重新載入小島，避免記憶體中殘留舊狀態。
