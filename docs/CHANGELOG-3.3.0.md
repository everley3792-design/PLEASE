# 3.3.0 修整紀錄

本版針對「整個 App 卡頓、掉 FPS、不斷閃爍」逐項量測後修正根本原因，並補上幾個操作與畫面上的問題。存檔格式不變，可直接沿用舊進度。

## 閃爍

- **GPU 圖層不再反覆建立／拆除。** 角色走過家具、做出擠壓動作時，原本每秒有 9–12 次圖層新增或移除；Android WebView 會把這種變化顯示成整塊閃一下。家具與角色會動的部位改為固定圖層，變動次數減半以上。
- **雲朵不再拖著整片背景一起變成獨立圖層。** 合成器動畫讓後面的山丘、草地（1250×1931）等全部被拆成額外圖層。雲改為一般位移、以一個裝置像素為單位移動。螢幕上的圖層總面積由約 9.4 個畫面降到約 6 個畫面，手機 GPU 的填充量與記憶體壓力明顯下降。
- 晴天時隱藏比螢幕大 5 倍的天氣畫布；沒有彩虹、沒有霧時，對應的全螢幕圖層也不再繪製。
- 角色的前後深度以約 2 px 為單位更新，走路時不再每一格改寫 z-index（每次都會觸發重新分層）。
- HUD 不再在閒置 5 秒後切換整個 `#app` 的 class（整份文件重新計算樣式、HUD 淡入淡出）。
- 啟動時直接使用上次的主題底色，並加入夜間資源；深色模式開啟 App 不會先閃一下淺色。系統列顏色與頁面背景一致，重複的主題通知會被忽略。
- WebView 開啟整頁預先光柵化，回到 App 或快速移動鏡頭時不會出現空白方塊；關閉邊緣拉伸效果。

## 卡頓與 FPS

- **畫面更新改以整數個螢幕刷新為單位。** 舊版用時間差跳格：90 Hz 手機被鎖在不穩定的 45 FPS，60 Hz 手機遇到 vsync 誤差會隨機少一次更新。現在 60/90 Hz 每格更新，120/144 Hz 每兩格更新；省電模式約 30 次／秒。
- **自適應節奏：** 手機持續來不及完成畫面時，改用穩定的半速節奏取代忽快忽慢的掉格；手指觸碰時立刻恢復全速，平穩一段時間後再自動嘗試全速。「完整動態」模式不套用。
- 切到其他分頁時，不再更新看不見的小島角色。
- 切換分頁不再為一個早已隱藏的導覽指示條強制同步排版（每次點分頁都重新排版整頁）。
- 換裝配件判斷是否鏡像時，改讀引擎已寫入的 `scaleX`，不再每次量測版面；隱藏中的工坊預覽也因此判斷正確。
- 雲朵每秒最多 24 次、且只有實際移動一個裝置像素時才重繪。

## 介面與操作

- 太陽與月亮移到 HUD 下方，不再被頂部膠囊遮住。
- 底部導覽目前分頁的圖示顏色與文字一致（原本是舊版黃色分頁的棕色）。
- 開啟面板時不再在整張面板外圍出現粗的焦點框。
- 背包抽屜展開時蓋在「跟隨鏡頭」按鈕上面，不再被它擋住第三個物品。
- 橫向畫面中，點頭像出現的快捷卡片移到右側並可捲動，不會被底部導覽擋住「完整檔案」按鈕。
- **返回鍵：** 現在可以關閉快捷背包與展開的資源膠囊。所有面板、編輯器、拍照模式都可一次返回關閉。
- 系統字體放大時，App 內文字跟著放大到 115% 為止，避免 HUD 文字互相重疊。
- 按下時的回饋改為不影響排版的亮度變化。

## 建置

- 專案內附共用的 debug 簽章金鑰 `app/debug.keystore`（密碼 `android`，僅供除錯版）。之後不論在哪台電腦或 GitHub Actions 建置，debug APK 都能直接覆蓋安裝，不再因簽章不同而必須解除安裝。
- 版本 3.3.0（versionCode 30300）。
- 瀏覽器回歸檢查增加到 57 項。
